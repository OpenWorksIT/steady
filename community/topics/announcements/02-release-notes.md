# Steady release notes
<!-- steady: pinned -->

Each new version of Steady gets a reply in this topic, so the whole history is in one place. To hear about each one, set this topic to **Watching** with the bell button at the bottom of the page.

Each reply follows the same outline:

- **Version and date**: when it reached the practice servers
- **For psychologists**: what you will see or do differently
- **For patients**: what changes on their side, and what they might ask you about
- **For the practice**: anything for the master clinician or the practice admin
- **To do**: anything you need to do, or "nothing"

## How versions are numbered

Steady has one number for all of it: the practice servers, the phone apps and the web app.

- A large update adds .1: 1.0.5 became 1.1.0.
- A small update adds .0.1: after 1.1.0 comes 1.1.1.

Your app's version is at the bottom of Settings. The master clinician also sees the server's version, and installs updates, under Settings > Server and updates. A new version reaches a practice's server only once OpenWorks IT has signed it.
